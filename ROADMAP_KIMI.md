## 0. Главное до начала работ

### 0.1. У Kimi два разных продукта, и оба — обычный HTTP по ключу

| | Kimi Platform (оплата за токен) | Kimi Code (подписка) |
|---|---|---|
| Что это | API для своих продуктов | Квота участника плана (Plus и выше; у прежних планов — Andante и выше) |
| Адрес Chat Completions | `https://api.moonshot.ai/v1`, Китай — `https://api.moonshot.cn/v1` | `https://api.kimi.com/coding/v1`, вне Китая — `https://api.kimi.ai/coding/v1`; там же `/responses` |
| Адрес Messages (Anthropic) | есть («Anthropic Messages API compatible»); точный адрес на прочитанных страницах не назван (hermes: `api.moonshot.cn/anthropic`) | `https://api.kimi.com/coding/` (`/v1/messages`), вне Китая — `api.kimi.ai` |
| Вход | `Authorization: Bearer <ключ>`; ключ из консоли платформы | Ключ из консоли Kimi Code (`kimi.com/code/console`), до 5 ключей, показывается один раз; hermes узнаёт такой ключ по началу `sk-kimi-`. Официальный CLI входит ещё и через OAuth (`kimi login`, браузер) |
| Модели | `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed`, `kimi-k3`; `kimi-k2.7-code`, `kimi-k2.7-code-highspeed`, `kimi-k2.6` — новым аккаунтам недоступны, снимаются в конце декабря 2026 | `k3` (окно до 1 млн — с плана Allegretto/Pro), `k3-256k` (без видео, вдвое дешевле по квоте), `kimi-for-coding` (K2.8 Preview), `kimi-for-coding-highspeed` |
| Лимиты | баланс и частота | скользящее окно 5 часов, месячная квота; у прежних планов ещё недельное окно; по желанию — «Extra Usage» (предоплата после исчерпания) |

**Вывод: сервис с официальным CLI не нужен.** У Claude и Antigravity подписка доступна только через их клиент, поэтому
там отдельные сервисы. У Kimi подписка отдаётся тем же HTTP, что и платный API, только с другим адресом и ключом. Оба
пути — встроенные провайдеры приложения, как `openai:` и `gemini:`.

### 0.2. Что говорят условия подписки

Со страниц справки Kimi Code (2026-11-27):

- сторонние клиенты разрешены: «Kimi Code allows members to use their benefits in both the official client and
  third-party platforms»; на странице сторонних инструментов названы Claude Code, OpenCode, Codex и **Hermes Agent**
  — агент общего назначения того же рода, что Меркурий;
- для стороннего инструмента ключ создаётся вручную в консоли;
- **«Tampering with the client identifier (User-Agent) is considered a violation»** — грозит приостановкой подписки;
  просят «сохранять настоящий идентификатор инструмента»;
- «Kimi Code membership benefits are designed specifically for programming scenarios»; для вызова моделей из своего
  продукта и для команд справка отсылает на Kimi Platform.

Что из этого следует:

1. **Свой честный `User-Agent`** (`Mercurius/<версия>`), никакой подделки. hermes здесь образцом не служит: на трёх
   путях он шлёт `User-Agent: claude-code/0.1.0` (`agent/agent_init.py:963`, `agent/auxiliary_client.py:2171-2172`,
   `:2208-2209`, `hermes_cli/doctor_connectivity.py:246-247`) — это и есть подделка идентификатора. Берём другой его
   путь: свои заголовки атрибуции (`plugins/model-providers/kimi-coding/__init__.py:12-20`,
   `agent/anthropic_adapter.py:511-512`).
2. **Риск остаётся в слове «programming scenarios».** Личный помощник — не только программирование. Полный текст
   условий не прочитан (этап 1). Это вопрос владельцу (0.4, п. 1).
3. Адрес `/coding` без `User-Agent` отвечает 403 (`agent/anthropic_adapter.py:474-475`); пустить ли наш — покажет
   только разведка ключом (этап 2). Если наш идентификатор не пускают, подписку **не делаем** и не обходим.

### 0.3. Чем Kimi отличается от того, что у нас уже есть

Обе стороны говорят на Chat Completions, а общий клиент `ChatCompletions` с диалектами у нас есть (`OpenRouter`,
`OpenAI`, `Gemini`). Нужен четвёртый диалект. Отличия (hermes и документация Kimi):

| Узел | Что требует Kimi | Что у нас сейчас |
|---|---|---|
| Рассуждение в потоке | поле `reasoning_content`, всегда раньше `content` | `StreamAccumulator` читает `reasoning` |
| **Возврат рассуждения** | ход ассистента с вызовами инструментов возвращается с `reasoning_content`; без него — 400. Нет текста — заглушка из пробела | `Message` рассуждение не хранит, `PayloadMapper` его не шлёт. **Главная работа пакета** |
| Усилие | K3 и K3.1: `reasoning_effort` `low`/`high`/`max`, параметр `thinking` слать нельзя; K2.x: `thinking: {type, keep: "all"}`; `thinking` и `reasoning_effort` вместе — 400 | объект `reasoning` либо строка OpenAI |
| `temperature` | не слать (K3 держит 1.0) | шлётся по диалекту |
| Потолок ответа | рассуждение входит в `max_tokens`; совет документации — не меньше 16 000 | как у Gemini — поднимать |
| Схемы инструментов | своё подмножество JSON Schema, иначе 400 «not a valid moonshot flavored json schema» | очистка есть только для Gemini (`Gemini\ToolSchema`) |
| История | пустой `tool_calls: []` — 400; результат инструмента — строго сразу за вызовом | проверить по коду |
| Поток вызовов | Kimi шлёт новый `id` на каждом фрагменте аргументов | слияние по `index` — проверить тестом |
| Кеш | неявный; `prompt_cache_options: {mode: "implicit", ttl}`, свои точки кеша — 400; usage: `prompt_tokens_details.cached_tokens` и верхний `cached_tokens` | способ кеша `provider` подходит |
| Сжатие | у hermes ломался разбор потока под `br` | проверить, что шлёт наш HTTP-клиент |
| Картинки и видео | платформа: `image_url` и `video_url` (base64), модели K3 читают видео; подписка: у hermes зрение выключено (`_PROVIDERS_WITHOUT_VISION`), по справке `k3-256k` не принимает видео | `MediaPart` — картинка и видео |

### 0.4. Вопросы владельцу (ворота)

1. **Принять ли оговорку «programming scenarios»** и делать ли подписку `kimi:` вообще. Варианты: А — только
   `moonshot:` по ключу платформы; **Б (предложение)** — оба провайдера, подписка выключена, пока не задан её ключ,
   в `self_info` и README — прямое предупреждение со словами Kimi.
2. **Имена** (предложение, по образцу пар `openai:`/`chatgpt:`, `anthropic:`/`claude:`, `gemini:`/`antigravity:`):

   | Что | Провайдер | Настройка |
   |---|---|---|
   | Kimi Platform, оплата за токен | `moonshot:` | `MOONSHOT_API_KEY` (так ключ называет документация Kimi; hermes — `KIMI_API_KEY`) |
   | Подписка Kimi Code | `kimi:` | `KIMI_CODE_API_KEY` |

3. **Регион.** По умолчанию международные адреса (`api.moonshot.ai`, для подписки — какой из `api.kimi.com` и
   `api.kimi.ai` рабочий для аккаунта владельца, покажет этап 2); свой адрес — `MOONSHOT_BASE_URL`,
   `KIMI_CODE_BASE_URL` (список разрешённых хостов, не произвольный адрес). Нужен ли китайский контур отдельным
   провайдером, как `kimi-coding-cn` у hermes, — предложение: нет.
4. **Вход в подписку: ключ из консоли или OAuth официального CLI.** Предложение: только ключ — это путь, который
   справка называет для сторонних инструментов. OAuth потребовал бы сервис с CLI (0.5, вариант В).
5. **Цена подписки в выборе модели** — 0 за токен, как у `claude:`, `chatgpt:` и `antigravity:`.
6. **Есть ли у владельца ключи** платформы и подписки и на каком экземпляре вести разведку (имя — в `SERVER.md`). Без
   ключей этапы 4–8 делаются на подставных ответах, как Anthropic, Bedrock и Gemini, а этап 2 и проверки вживую
   переносятся в `brief/history.md#ждёт-владельца`.
7. **Референсы** — список 0.5.
