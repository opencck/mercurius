# План: фаза 2 — канал и модель

Временный план реализации фазы 2 из `ROADMAP.md`. Удаляется, когда фаза закрыта.

## Пакеты (параллельно, каждый в своём репозитории)

- `packages/llm` — `LlmClient`, `ChatRequest`/`ChatResponse`, поток событий, `OpenRouterClient`, `RetryingClient`, каталог моделей.
- `packages/connectors` — `RouteFactory::fromUri()`: напрямую, HTTP CONNECT, SOCKS5, VLESS; цепочки; редактирование секретов в URI.
- `packages/messenger` — `Channel`, `IncomingMessage`, `OutgoingMessage`, `SendResult`, Telegram: API, канал, парсер обновлений, проверка секрета вебхука, long polling, дедупликация.

## Приложение

1. Миграция `0002`: пользователи и роли (один владелец), учётные записи в каналах, диалоги (один открытый на чат), сообщения, вызовы моделей с расходом.
2. Конфигурация: токен бота, id владельца, секрет вебхука, ключ OpenRouter, `VLESS_URI`, модель и уровень рассуждений по умолчанию.
3. Репозитории PostgreSQL за интерфейсами домена; в тестах — реализации в памяти.
4. `AccessService` — пользователь по учётной записи канала; владелец создаётся по `TELEGRAM_ADMIN_ID`; остальным — отказ (регистрация пользователей — позже).
5. `ConversationService` — открытый диалог чата, история, `/new`.
6. `ChatService` (`MessageHandler`) — запрос к модели с историей, ответ потоком: заглушка → правки не чаще раза в 1,5 с → итог; длинный ответ — продолжениями; учёт расхода в `llm_calls`.
7. Telegram: при заданном `APP_URL` — вебхук `POST /telegram/webhook` с проверкой секрета (ответ сразу, обработка асинхронно, порядок внутри чата), иначе long polling.
8. Маршрут к OpenRouter: HTTP-клиент поверх `RouteFactory::fromUri(VLESS_URI)`.
9. Сборка образа с пакетами (`packages/` в контексте Docker), CI основного репозитория с сабмодулями пакетов.

## Готово, когда

Владелец пишет боту и получает потоковый ответ с учётом истории; чужой пользователь получает отказ; запрос к модели
работает через VLESS и напрямую; в ядре нет упоминаний Telegram и OpenRouter вне пакетов и их подключения;
`composer check` зелёный в каждом репозитории.
