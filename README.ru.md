# Меркурий (Mercurius)

[English](README.md) | **Русский**

Меркурий — автономный персональный агент. Его ставят на свой сервер через Docker Compose и общаются с ним через Telegram-бота. Он рассчитан на любые дела: поиск в интернете, работу с серверами по SSH, написание кода и ведение проектов, планирование, исследования и тестирование.

**Статус:** ранняя разработка. Спецификация готова, устанавливать пока нечего.

## Что планируется

- Агентский цикл с инструментами, лимитами в коде и подтверждением опасных действий владельцем.
- Оркестратор, который сам решает, когда разделить задачу между агентами-воркерами.
- Выбор модели под каждую часть задачи по цене и скорости.
- Долговременная память: профиль, всегда лежащий в контексте, проекты и их задачи, факты с доверием и историей, фоновая консолидация.
- Серверы по SSH, в том числе через VLESS; браузер; скиллы и MCP-серверы.
- Подробные трассы каждого запуска для диагностики и оптимизации.
- Сеть агентов: экземпляры Меркурия подключаются друг к другу по WebSocket и используют друг друга как агентов.

## Стек

PHP 8.2+, AMPHP v3 / Revolt, [`opencck/server`](https://github.com/opencck), PostgreSQL; модели — через OpenRouter. В каждом репозитории — PHPUnit, PHPStan и Psalm.

## Репозитории

Компоненты, полезные вне Меркурия, живут в отдельных репозиториях и подключаются сабмодулями в `packages/`:

| Репозиторий | Назначение |
|-------------|------------|
| [`mercurius-llm`](https://github.com/opencck/mercurius-llm) | Единый интерфейс вызова больших языковых моделей: сообщения, инструменты, потоковый ответ, учёт токенов и стоимости, ошибки и повторы. |
| [`mercurius-connectors`](https://github.com/opencck/mercurius-connectors) | Маршруты исходящих соединений как фабрика `SocketConnector` из Amp: напрямую, через HTTP CONNECT-прокси, SOCKS5, VLESS (на `amphp/vless`) и их цепочки. |
| [`mercurius-messenger`](https://github.com/opencck/mercurius-messenger) | Единый интерфейс канала связи с нормализованной моделью сообщения и адаптер Telegram Bot API (webhook и long polling). |
| [`mercurius-command-policy`](https://github.com/opencck/mercurius-command-policy) | Классификация команд по опасности и политика исполнения: чтение — только если доказано, список «никогда», матрица «роль × группа серверов», разовые разрешения, квоты и журнал решений. |
| [`mercurius-memory`](https://github.com/opencck/mercurius-memory) | Долговременная память агента: хранилище фактов с версиями, доверием, происхождением и сущностями, лексический поиск с гейтом релевантности и голографическими представлениями (HRR), фоновая консолидация. |
| [`mercurius-browser-service`](https://github.com/opencck/mercurius-browser-service) | Сервис браузера для агента: Chrome под управлением Puppeteer за HTTP API на Fastify, поставляется Docker-образом. |
| [`mercurius-mcp-client`](https://github.com/opencck/mercurius-mcp-client) | Асинхронный клиент Model Context Protocol (MCP) с транспортами stdio и HTTP. |
| [`mercurius-peer`](https://github.com/opencck/mercurius-peer) | Протокол связи экземпляров Меркурия по WebSocket: карточка агента, задача, поток статусов, итог, отмена и переподключение — клиент и сервер. |
